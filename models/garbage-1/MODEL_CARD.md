# garbage-1 模型说明

本项目自写的字符级因果语言模型，用于本地垃圾话娱乐实验。当前默认 checkpoint 有 **1,000,000 个唯一可学习参数**，从随机初始化开始训练，没有下载预训练权重，也没有调用远程模型。推理与日常标注后的在线更新在本机使用 MLX / Metal。

- 元数据：`checkpoints/20261021T082320Z-202a56a3-52d.json`
- 权重数组摘要：`8c304ba82251bc46e6f6de1055a7a59c18c9db011c88fd72ae187ca0081318fa`
- 数据组合来源摘要：`8766084c7eb26c5b1ef79d4bbed1804b53f72a54c3a8f524173871259eacc1b8`
- 恰好 1,000,000 个可学习值，全部 FP32；裸数组本体 4,000,000 字节，NPZ 另有容器开销。
- 两层 pre-LN causal Transformer，d_model=160、heads=8、context=174、FFN=[858,859]、词表1323；embedding/output 权重绑定，dropout=0。

参数数公式为 `V(d+1) + Cd + 8d² + 20d + (2d+1)(F1+F2)`。代入当前配置得到 `213003 + 27840 + 204800 + 3200 + 551157 = 1000000`。满 context 训练使全部位置行参与学习，没有专门凑参数的占位权重。

## 初训与数据边界

训练集14508句、验证集806句、测试集806句，来源为16000条规则生成句和120条明确标为 curated_seed 的完整句。按完整句 NFC 文本 SHA-256 排序固定划分，同一句不会跨集合；tokenizer只在训练集拟合。规则模板与词块会跨集合共享，因此这里的指标是域内拟合，不代表通用中文或未见模板泛化。

初训使用本机 PyTorch MPS FP32、AdamW，batch=16、learning_rate=0.001、weight_decay=0.01，在训练 packed 流上跑了 **2 轮，共420步（每轮210步）**，无autocast/量化。最后一批训练 loss 为1.0351；每次验证取4个 batch，最后一次 validation loss 为0.9642。初训显式使用 highest FP32 matmul 精度并关闭 TF32。日常增量更新使用 MLX / Metal 上的无动量 SGD，学习率0.003、全局梯度范数裁剪1；保存权重和步数即可恢复，不需要 AdamW 状态。

## 推理与人工评价

应用没有针对黑话、脏话或成人话题的敏感词表、拒答模板、内容打码或生成后审核；初训是 next-token 交叉熵训练，在线更新是由真实点赞驱动的监督学习，没有额外拒答训练阶段。内容原文保存、显示和参与标注。点踩后的正向训练排除由用户评价决定。

当前 tokenizer 在训练集上拟合为1059个训练字符和8个控制 token，并加入256个 UTF-8 byte fallback token，总词表1323。遇到词表外字符时，整字按UTF-8字节编码，不会折叠到UNK；因此新投喂句中的生僻字也能作为明确 token 参与在线学习。缺少相关语料时，仍不能保证模型学会某个话题或黑话。

逐步取完整词表argmax，温度0；不做top-k、概率采样、重复词惩罚或规则回退。网页从训练句前四字开场池随机选输入，因此不同点击可以不同；固定权重和prompt的输出固定。最多续写64 token，遇EOS停止。固定种子16组开场重复推理全部一致，16/16在上限内输出EOS。

生成输出先登记为pending。真实点赞句进入正向池；用户从显示器下方投喂的完整句直接作为正向样本排队训练。后台混合当前正向句、此前点赞句和可信种子回放做小步SGD。点踩仅从后续正向目标与回放中排除，不能撤销历史梯度，也不是DPO/RLHF。评价与投喂句去重，保存在独立SQLite；持久队列、单writer lease、版本化checkpoint、原子指针和last_job_result/last_job_id处理重启及确认失败边界。

## 开发边界

MLX与Torch CPU共享canonical FP32权重并已实测映射；CUDA适配器提供相同权重/生成/更新接口，要求显式可用CUDA设备，目前未在CUDA硬件验证。dense FFN、architecture/backend registry、辅助损失、格式版本和run_id为未来MoE保留扩展；当前没有路由器或专家，不宣称已实现MoE。新架构应新建run并显式迁移权重，分别报告总参数和激活参数，继续读取独立标注库。
