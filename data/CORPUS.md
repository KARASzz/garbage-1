# 本地垃圾话语料说明

这份语料供纯本地、无 LLM 的中文垃圾话生成器按类别和标签组合。语气直接、带常见脏字；内容不使用受保护群体辱称、真实人物姓名或威胁。碎片以短语为主，句型 literal 保存固定连词和标点；槽位通过语义标签控制主语、谓语、宾语和主题搭配。可选槽的标点依附在槽位自身，省略时不留下孤立标点。

## 固定种子模拟与检查

- 使用项目 `.venv` 调用原始 `validate_source()` / `matches()`；JSON 解析、语料校验、唯一 ID 和 40 个模板的所有槽位候选均通过。917 条旧碎片的 ID 与文本逐条核对一致。
- 新增 **256** 条均为新文本，按原类别和标签逐槽检查 **256 / 256** 可达；全库可达 **1100** 条、储备 **73** 条。
- 直接从 JSON 构建候选池，以种子 `20261021` 按生成器的模板权重、槽位权重、可选槽概率和最近使用降权规则模拟 **10,000** 句：不同句子 **9890 / 10,000**（**98.90%**），连续重复 **0**，覆盖模板 **40 / 40**，常用脏字比例 **82.92%**。
- 抽取块数：3 块 1812 句, 4 块 5032 句, 5 块 3156 句；生成长度范围 **18–62** 字。另对每个模板各取 10 句、奇数句关闭可选槽、偶数句启用可选槽，共 **400** 句；全部满足输出长度和标点检查。
- `curated.jsonl` 解析和字段校验通过：**120** 行，主题各 30 行；句长 **20–55** 字，每句含 1–2 处常用脏字及明确的反转。
- 每主题抽取一条含 v2 新块的完整输出并人工通读，语法、槽位配价和笑点均可读：
